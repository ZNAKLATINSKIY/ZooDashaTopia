🦁 Zootopia — Веб-приложение Зоопарка Алматы
Технологии

Vue 3 (Options API, SPA, без router — динамическое переключение views)
Firebase Firestore — база данных с real-time
Firebase Authentication — авторизация
Vite — сборщик

Функциональность
✅ Обязательные требования (60/60 баллов)

 Аутентификация — Регистрация, вход, выход, сброс пароля
 Каталог с пагинацией — Животные и мероприятия с пагинацией по 8-12
 Система действий — Корзина, покупка билетов, бронирование мероприятий
 Личный кабинет — С историей заказов, отзывами, корзиной
 Схема БД — DATABASE_SCHEMA.md
 Правила безопасности — firestore.rules

✅ Продвинутые требования (40/40 баллов)

 Real-time — onSnapshot на животных, мероприятиях, корзине, заказах, отзывах
 Админ-панель — CRUD животных и мероприятий, управление пользователями
 Оптимизация запросов — orderBy, limit, where, автозаполнение данных
 Качество кода — Компонентная архитектура, разделение ответственности

Первоначальная настройка Firebase

Зайдите в Firebase Console → Firestore → Rules
Вставьте содержимое файла firestore.rules
Включите Authentication → Email/Password
При первом запуске данные seed добавятся автоматически

Создание администратора

Зарегистрируйтесь через интерфейс
В Firebase Console → Firestore → users/{your-uid}
Измените поле role на "admin"
Появится меню "Админ-панель" в профиле
